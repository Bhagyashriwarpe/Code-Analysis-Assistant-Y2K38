# CodeGuard AI Y2038 VS Code Prototype

1. Start the Flask backend on port 5000.
2. Open this folder in VS Code.
3. Package/install the extension with your normal VS Code extension workflow.
4. Select code and run `CodeGuard: Analyze Selection` or `CodeGuard: Remediate Selection`.
5. The backend URL can be changed through `codeguard.backendUrl`.
